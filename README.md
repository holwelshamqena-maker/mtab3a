# نظام فواتير مطبعة طارق أبوهمام

نسخة محدثة من نظام الفواتير بإضافة:

- أنواع العملاء: فرد، مكتب، تجاري.
- صفحة مستقلة باسم «قائمة الأسعار» لإضافة الأصناف والوحدات والأسعار حسب نوع العميل.
- تخزين قائمة الأسعار في Firebase Realtime Database تحت المسار `pricingCatalog`.
- ظهور قائمة الأصناف الخاصة بنوع العميل عند فتح فاتورة جديدة.
- تعبئة الوصف والسعر تلقائيًا عند اختيار صنف من قائمة الأسعار، مع إمكانية تعديل السعر يدويًا.

## الرفع على GitHub

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع ملف `index.html` إلى المستودع.
3. فعّل GitHub Pages من إعدادات المستودع إذا رغبت في تشغيله كصفحة ويب.
4. تأكد من إعداد قواعد Firebase للسماح للمستخدم المصرح له بقراءة وكتابة `pricingCatalog`.

> ملف Firebase الحالي موجود داخل الكود كما كان في النسخة الأصلية. يفضّل تقييد قواعد Firebase بالمصادقة قبل النشر العام.

## الفواتير الجديدة وترحيل الرصيد

عند الضغط على «إضافة فاتورة» يظهر اختيار:

- **فاتورة جديدة — ترحيل الرصيد القديم**: يحفظ الرصيد المتبقي قبل الفاتورة في `previousBalance` ويظهر في التقرير مع قيمة الفاتورة الجديدة وإجمالي الحساب.
- **إضافة على الفاتورة الحالية**: تضاف كعنصر جديد داخل دفعة الفاتورة الحالية نفسها، ولا تُضاف إلى الفواتير القديمة التي تم ترحيلها.

الرصيد المرحّل يظهر في أعلى الفاتورة الجديدة كسطر مستقل، ويُحتسب مرة واحدة فقط ضمن إجمالي الحساب. ويظهر أسفل الفاتورة إجمالي الحساب القديم والجديد في جميع الحالات، مع خصم التحصيلات المسجلة.

## أدوات البيانات والنسخ الاحتياطي

من زر «أدوات البيانات» يمكن تنزيل نسخة احتياطية بصيغة JSON تشمل العملاء وجميع الفواتير والتحصيلات وقائمة الأسعار، ثم استرجاعها لاحقًا من نفس الصفحة بعد تأكيد الاستبدال. كما تعرض الصفحة حجم البيانات الفعلي التقريبي، مع سعة مرجعية يحددها المستخدم لحساب المساحة المتبقية؛ لأن Firebase لا يتيح للواجهة معرفة الحصة المتبقية الفعلية للحساب مباشرة.

## لوحة التحكم المتجاوبة

- الصفحة الأولى بعد تسجيل الدخول أصبحت لوحة إجمالي حسابية.
- قائمة الأعضاء تظهر في الجانب الأيسر مع بحث سريع واختيار العضو.
- الإحصائيات الحسابية في المنتصف: إجمالي الفواتير، المحصل، والمتبقي.
- أزرار الإجراءات السريعة في الجانب الأيمن: إضافة عضو، فاتورة، تحصيل، إدارة الأعضاء، وقائمة الأسعار.
- التصميم متجاوب مع شاشات الكمبيوتر والهواتف.
